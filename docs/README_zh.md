# Karaoke Song Manager (卡拉OK歌曲管理)

[English](../README.md) | [日本語 (Japanese)](README_ja.md)

一款本地Web应用程序，帮助您从YouTube视频中筛选和管理卡拉OK歌曲。内置便携式Python环境。

## 特点
- 便携式环境：无需在Windows上全局安装Python即可运行。
- 简洁架构：核心代码隐藏在 `core/` 目录中，防止用户误删。
- 静默启动：通过VBScript在后台启动服务器，不会弹出黑色命令行窗口。
- 类似Notion的UI：在美观的SPA界面中管理歌曲、播放量、标签和下载状态。

## 初始设置
1. 复制 `.env.example` 并重命名为 `.env`。
2. 打开 `.env` 并填入您的YouTube Data API v3密钥（`YOUTUBE_API_KEY=...`）。
3. 双击运行 **`setup.bat`**。这将自动下载轻量级Python环境到 `bin/` 目录，并安装所需的库。（仅需执行一次）

## 运行方法
平时请双击 **`run.vbs`** 启动应用。
- 它可以静默启动后台服务器，并在默认浏览器中打开 `http://127.0.0.1:5000`。
- 如果要安全关闭服务器，请前往应用内的 "設定とバックアップ"（设置与备份）选项卡，点击 "服务器关闭" 按钮。

## 卸载
直接删除整个应用程序文件夹即可。本程序不会修改系统注册表或全局环境变量。
