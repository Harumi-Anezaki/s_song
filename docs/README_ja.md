# Karaoke Song Manager

[English](../README.md) | [中文 (Chinese)](README_zh.md)

YouTubeの動画から楽曲を選別し、再生回数やタグを管理するローカルWebアプリケーションです。商用レベルのポータブルPython環境を内包しています。

## 特徴
- ポータブル環境: Windowsシステムを汚さず、Pythonのインストール不要で動作します。
- クリーンな構成: 重要なソースコードは `core/` に隠蔽され、エンドユーザーが誤って破壊するのを防ぎます。
- サイレント起動: VBScriptにより黒いコマンドプロンプト画面を出さずにバックグラウンドで起動します。
- NotionライクなUI: 曲の管理、再生数の集計、タグ付けなどをSPAで行えます。
- タグ名の直接編集: テーブル上のドロップダウンにある3点ボタンから、タグの名前を直接変更できます。
- スプレッドシートライクな操作: セル右下からのドラッグアンドドロップによる一括入力などに対応しています。

## 初回セットアップ
1. `config.json` をテキストエディタで開き、取得したYouTube Data API v3のキーを入力します (`YOUTUBE_API_KEY` の部分)。
2. **`setup.bat`** をダブルクリックして実行します。自動で軽量版Python環境が `bin/` フォルダ内に構築され、必要なライブラリがインストールされます。（初回のみ実行）

## 起動方法
普段は **`run.vbs`** をダブルクリックして起動してください。
- バックグラウンドでサーバーが起動し、自動的に既定のブラウザで `http://127.0.0.1:5000` が開きます。
- サーバーを完全に終了させる場合は、アプリ画面の「設定とバックアップ」タブにある「サーバーを終了する」ボタンをクリックしてください。

## アンインストール
アプリケーションのフォルダごと削除するだけで完了します。レジストリやシステム環境変数は一切変更していません。
